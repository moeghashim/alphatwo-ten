The factory is the part of tenwhy that builds tools. Each tool becomes a specialist agent's capability — a CLI binary and a Skill markdown, packaged together in its own GitHub repo.

The factory and the workforce share infrastructure but never call each other directly. The only handoff is a tool getting published to the catalog. Click ▶ Watch a build to see a build packet travel through every stage.

Zones  Factory stages run in Sapiom µVMs. Workforce stages run per-customer alongside Maestro. The Catalog is the wall between them.
